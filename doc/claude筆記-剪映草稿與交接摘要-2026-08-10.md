## 一、剪映草稿格式／路徑／分享／範本／版控 查證結果

背景：使用者在剪映桌面版編輯專案「視覺定調-圖層混合文字錯位」時，想知道還沒匯出成 MP4
之前的草稿放在哪裡、能不能分析內容、範本能不能改、能不能分享給別人協作。以下由 subagent
上網查證（非憑訓練記憶），部分資訊有版本差異，已註明可信度。

### 1. 草稿格式與路徑

不是單一檔案，是一個資料夾：核心是 `draft_content.json`（時間軸/軌道/素材配置）+
`draft_meta_info.json`（草稿名稱、建立時間、封面圖）。

Windows 路徑（查到兩種說法，可能因版本而異，建議實測確認）：

```
C:\Users\{使用者名稱}\AppData\Local\JianyingPro\User Data\Projects\com.lanying.editor.draft\
C:\Users\{使用者名稱}\AppData\Local\JianyingPro\UserData\Projects\com.lveditor.draft\
```

最可靠的確認方式：在剪映內開啟專案 →（若該版本有）「草稿參數」或選單裡的路徑資訊，直接顯示
這個草稿實際存放路徑。也可在「設定 → 全局設定 → 草稿位置」查看/更改。

### 2. 能不能用一般工具打開分析

本質是 JSON，但**加密與否查到互相矛盾的說法**——有回報舊版本（如 5.9.0）是明文可直接用記事本
打開；也有回報新版本會加密，需要專門解密工具（GitHub 上有人做了 `jy-draftc`）。

建議：用記事本或 VS Code 打開 `draft_content.json`，看到 `{"materials":...` 可讀文字即明文，
亂碼即加密版本。

### 3. 範本格式與能否修改

範本本質上是「創作者發布的完整草稿專案」，透過「剪同款」功能讓其他人套用、替換裡面的素材。

**沒有查到官方提供「直接編輯剪映內建範本原始檔」的功能**——只能套用範本後換素材，改不了範本
底層結構。若想自製範本發布，官方路徑是升到創作者 Lv.5（高階創作者）解鎖資格，剪好影片後匯出時
選「發布為剪同款」。

### 4. 分享到雲端協作編輯

- **剪映雲空間（官方）**：可以，會員可將草稿同步雲端，同帳號換裝置可接續編輯，免費額度 1GB。
  但**不支援多人同時即時共編同一草稿**（會衝突），是「跨裝置接續編輯」而非「多人共編」。另有
  企業版/團隊協作版，具備團隊共享空間、多人共創分鏡等（付費方案）。
- **分享到 Google Drive / OneDrive 給別人開**：**未查到官方支援**。技術上可手動把草稿資料夾
  丟上雲端硬碟讓別人下載回對應路徑，但非官方功能，有路徑對應/加密/素材遺失風險，沒有社群教學
  驗證過此法可行，不建議假設能用。

**現場發現**：使用者截圖顯示剪映介面右上角實際有一顆「**分享**」按鈕（在「匯出」左邊），比
上網查到的資訊更準確——建議使用者直接點開看跳出什麼選項，以此為準。

### 5. 類似 Git 的版本控制

**沒查到有正式版本控制系統**。剪映提供的是：

- 編輯內撤銷/歷史記錄按鈕，但有步數限制（社群回報約 10-20 步）
- 隱藏功能「恢復草稿備份」（連點設定頁版號 10 下叫出調試視窗 →「功能操作」→「恢復草稿備份」），
  可挑選自動保存的舊版本回復，但屬自動快照式備份，非可命名/可分支/可 diff 的版控
- 企業版「團隊腳本」是前期分鏡腳本階段的多人協作，非時間軸剪輯本身的版本追蹤

沒有查到分支、版本比對、合併、版本歷史清單瀏覽功能。此為「查無資料」的推論，非官方明講
「不支援」，若此功能對使用者很關鍵，建議直接問剪映客服或官方社群論壇確認。

### 補充：CapCut（國際版）路徑對照

CapCut 國際版 Windows 路徑：`C:\Users\{username}\AppData\Local\CapCut\User Data\Projects\
com.lveditor.draft`，結構與剪映高度相似（同源軟體），但**帳號體系、雲端服務是分開的**，
CapCut 資料不會出現在剪映帳號裡，反之亦然。
