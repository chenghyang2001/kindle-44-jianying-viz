# 交接文件：工會大會團隊留念影片

**建立日期**：2026-08-10（公司機 B00332 session）
**執行機器**：Yama-Desktop（家用雙螢幕機）— 預計今晚或明早開工

## 任務

用 CapCut（剪映）+ 全域 skill `capcut-photo-video`，把同事照片做成一支慶祝工會大會的留念影片。

## 開工前要準備

1. **同事照片**：建議 8–12 張，橫式直式皆可，放到 `~/workspace/<年份+主題>/素材/`
   （例如 `~/workspace/2026工會大會/素材/`）
2. **片尾祝賀語文字**：先想好一句，例如「工會大會 團隊留念」「XX工會 202X年度大會」。
   Skill 開工時會用 AskUserQuestion 問片尾字卡風格（極簡置中／相框感／溫馨風）與片尾特效
   （溫馨光斑飄動／純文字動畫／愛心飄落），但文字內容本身要先想好、直接回答就行。

## 背景音樂建議（本次 session 已研究）

在 CapCut「音樂」分頁搜尋以下關鍵字，依想要的調性挑一個：

| 優先序 | 搜尋詞 | 調性 | 備註 |
| --- | --- | --- | --- |
| 1 | `upbeat corporate` | 專業又有活力，公司／團體活動標準款 | ✅ 已在本帳號驗證過真的搜得到、可用（軌名「Upbeat Corporate Music」，之前在其他 CapCut 練習專案用過） |
| 2 | `corporate celebration` / `team celebration` | 比 corporate 更有慶祝感，適合頒獎／週年氣氛 | 未驗證，需現場試聽挑一首 |
| 3 | `feel good acoustic` / `happy ukulele` | 溫暖、沒那麼「開會感」，適合當團隊回憶影片 | 未驗證，需現場試聽挑一首 |

套用時的固定參數（`capcut-photo-video` skill 已內建，不用自己設）：音量 -6dB、淡入淡出各 1 秒、
鋪滿全片並裁到跟總長一致。

## 開工方式

在 Yama-Desktop 開一個新的 Claude Code session，對話直接說類似：

> 用 capcut-photo-video skill，幫我把同事照片做成工會大會留念影片，音樂用 `upbeat corporate` 搜尋結果

Claude 會照 skill 的 Phase 0–6 走（不需要重新校準座標，`capcut-photo-video` 就是在 Yama-Desktop
驗證出來的）：

- **Phase 0** 環境檢查（CapCut 已安裝／登入／Pro、是否已開啟、螢幕與前景視窗）
- **Phase 1** 建立專案骨架（16:9，全選照片一次新增到時間軸）
- **Phase 2** 全部照片套用「背景：模糊」填滿（不裁切人物）
- **Phase 3** JSON 精算每張照片時長（目標總長 45–50 秒，片尾抓 8–10 秒，剩餘秒數 ÷ 照片張數）
- **Phase 4** 片尾字卡（貼上你想好的祝賀語文字）
- **Phase 5** 背景音樂（上表任選一個關鍵字搜尋並拖曳加入）
- **Phase 6** 匯出 1080P mp4 + ffprobe 驗證 duration/resolution + 抽畫格肉眼驗收

## 匯出後：本次 session 已釐清的限制

- **VPS 不能跑 CapCut**：`n8n2vps-hub` 那台 VPS（187.127.109.145）是無 GUI 的 Linux 主機（只跑
  systemd 服務），CapCut 桌面版是 Windows/Mac 應用，沒辦法在 VPS 上做桌面自動化。影片製作只能留在
  有 GUI 的 Windows 機器（Yama-Desktop 或公司機 B00332）完成。
- **上傳 Google Drive**：匯出後直接在 Yama-Desktop 用 `rclone copy <file> gdrive:<folder-id>
  --drive-root-folder-id <id>` 上傳即可，不需要經過 VPS。
- **發布 YouTube**：目前沒有設定 YouTube Data API / OAuth 整合，這部分還沒有自動化能力，需要先做
  一次性設定（需要你本人做互動式 Google 登入授權），或先手動上傳。而且影片含同事照片，開工前建議
  先想清楚兩件事：(1) YouTube 可見度要設 公開／不公開列出／私人？(2) 同事是否同意影片公開播出？

## 已知 CapCut 踩坑參考

詳見同資料夾 `doc/交接文件-capcut-practice.md`，特別留意：

- CapCut 開機常停在「上一次專案的分享完成對話框」，不要對著殘留畫面亂點，先確認畫面內容
- 拖曳素材／音樂到時間軸要用「慢速拖曳」，直接跳到終點的拖曳幾乎必失敗
- 背景音樂用「拖曳」加入時間軸，不要點「+」（點「+」只會觸發預覽播放，不會真的加入）
- JSON 改完一定要完全關閉 CapCut 再重開驗證，不能只看「已自動儲存」就相信
