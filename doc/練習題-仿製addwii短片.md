# 練習題：仿製 addwii 空氣清淨機開箱短片（33 秒版）

範本影片：<https://www.youtube.com/shorts/9tnTPt5j4jc>
（addwii Clean Room 居家無塵室頻道，「守護孩子的靈感與健康！addwii 智能空氣清淨機正式上線」）

## 為什麼是這支片

1. 結構單純、無特效，適合當 CapCut 初學練習的「命題作文」——重點在剪接節奏、字幕、品牌收尾，不是進階合成。
2. 片中第 3 段是「受訪者證言 + 字幕框」，剛好可以拿來當 [[capcut-practice-project]] Stage 3 卡住的**有聲素材測試題**：如果你這次找到的素材真的有內嵌語音，自動字幕/擷取音訊應該要能正常輸出。

## 範本 Shot List（對照原片時間軸）

| 段落 | 時間 | 內容 | 對應技能 |
| --- | --- | --- | --- |
| A 開場 Hook | 0:00–0:02 | 黑場淡入 → 情境畫面 + 大字文案 | 淡入轉場、文字進場動畫 |
| B 安裝 B-roll | 0:02–0:16 | 師傅搬運/安裝產品，2-3 顆鏡頭硬切 | 分割、裁切、無縫刪除 |
| C 證言片段 | 0:16–0:29 | 受訪者對鏡頭說話 + 白底字幕框 | **自動字幕**、擷取音訊、字幕樣式 |
| D 品牌收尾 | 0:29–0:33 | 純白底 + Logo 淡入 | 純色背景、Logo 動畫 |

## 你的練習版腳本

目標總長 25–35 秒，9:16。用 CapCut 內建免版稅素材庫湊素材即可，不用自己拍。

### Lesson 練習 7.1｜找到真正有聲的素材（解 Stage 3 卡點）

1. 資料庫搜尋關鍵字，**避開**已知無聲黑名單風格：`studio`／`news`／`green screen`／`talks to camera`
2. **改用**這幾類關鍵字（隨手拍/同步收音機率較高）：`vlog`、`selfie talking`、`interview response`、`street interview`、`talking outdoors`
3. 每支候選素材加入時間軸後**點選它，看右側屬性面板分頁列**：
   - 有「影片／**音樂**／速度／插入動畫／調整／AI風格化」6 個分頁 → 有內嵌語音，可用
   - 只有 5 個分頁（缺「音樂」）→ 靜音 B-roll，換下一支
4. 找到有聲素材後，**先不要急著剪**，右鍵測一次「擷取音訊」跟「產生字幕」，確認兩者都有實際輸出（不是灰階、不是跑到 100% 但空白），驗證通過再進入下一步

> 這一步就是本練習題的核心價值：直接解掉交接文件記錄的 Stage 3 卡點，不用再猜。

### Lesson 練習 7.2｜段落 A：開場 Hook（目標 2 秒）

1. 找一顆吸睛的情境素材（人物特寫、商品特寫皆可）
2. 素材最前面加「淡入」轉場（黑場 → 畫面），時長 0.3–0.5 秒
3. 疊加一行大字文案（例如仿照原片风格寫一句「XX 問題？答案在這！」），套用「打字機」或「彈入」進場動畫，停留時間不超過 2 秒

### Lesson 練習 7.3｜段落 B：B-roll（目標 10–14 秒）

1. 找 2-3 顆與主題相關的動作型素材（開箱、組裝、操作、使用過程皆可）
2. 每顆只留動作最清楚的 3-5 秒，用分割 + 無縫刪除裁掉多餘畫面
3. 鏡頭之間直接硬切（不用轉場），保留真實感
4. 選其中一顆做「縮放」關鍵幀（片頭 100% → 片尾 120%），做一個簡單推鏡效果

### Lesson 練習 7.4｜段落 C：證言 + 字幕（目標 10–13 秒，本題重點）

1. 放入 7.1 驗證過「有音樂分頁」的素材
2. 右鍵「產生字幕」，等待輸出，檢查：
   - 逐字稿準確度（跟實際講話內容比對）
   - 簡繁轉換是否正確（有沒有跑出簡體字）
3. 套用一個「白底黑字」或「膠囊底色」字幕樣式，模仿原片的證言字幕框質感
4. 若這支素材音量偏小/有雜訊，套用「降噪」+ 音量增益

### Lesson 練習 7.5｜段落 D：品牌收尾卡（目標 3–4 秒）

1. 新增一個純色背景素材（白色或你喜歡的品牌色）
2. 疊上文字（可以是任意練習用的品牌名/slogan），套用「淡入」進場動畫
3. 前一個段落到這張卡之間加「淡出轉黑」或直接「淡入」收尾，呼應開場的淡入手法

### Lesson 練習 7.6｜配樂與匯出

1. 加一軌背景音樂，音量壓到不蓋過人聲（-15dB～-20dB 左右）
2. 有人聲的段落（段落 C）用音量關鍵影格把音樂再降低一點（ducking）
3. 匯出設定：1080×1920、H.264 mp4、幀率跟來源素材一致即可（不用刻意升 60fps，[[capcut-practice-project]] 已驗證過幀率對檔案大小影響不大）

## 驗收標準

- [ ] 找到並確認至少 1 支「有音樂分頁」的素材，且擷取音訊/自動字幕有實際輸出（非空白）
- [ ] 成品時長 25–35 秒，四段結構（Hook / B-roll / 證言字幕 / 品牌收尾）齊全
- [ ] 至少用到：1 個轉場（淡入）、1 組關鍵幀（縮放推鏡）、1 個字幕樣式、1 條背景音樂
- [ ] 匯出成功，檔案為 9:16、1080p mp4

## 與現有練習專案的關係

這題不屬於官方 24 堂課的任何一個 Stage，是額外的「命題實作」練習，用來：

1. 驗證 Stage 3 卡住的「有聲素材」問題有沒有解掉（如果 7.1 順利找到有聲素材，可以直接把這個結論回填到 `doc/交接文件-capcut-practice.md` 的 Stage 3 章節）
