## ⚠️ 踩坑總表：三個 CapCut 桌面版真實限制（Stage 3-4 發現）

1. **練習素材完全無語音音軌**（Stage 3 連續三堂課命中）：`0806` 專案主視頻用的是 CapCut 內建免版稅素材（"Used Damaged Notebook Schoolwork Paper Template Background"），完全沒有人聲/語音音軌。導致：
   - **擷取音訊**（右鍵選單）→ 灰階不可點擊
   - **產生字幕/逐字稿**（右鍵選單 + 文字分頁自動字幕面板）→ 面板可開、按鈕可點，但點「產生」後沒有任何輸出（沒報錯，就是靜默無結果）
   - 對應地，**降噪**這類「音軌屬性」功能不受影響（背景音樂軌本身就有降噪開關，跟人聲無關），可正常使用
   - **因應方式**：直接說明這是素材限制，改用功能對等的替代操作示範（背景音樂軌代替人聲軌、手動文字代替語音辨識文字），不必真的去找/錄一段有人聲的素材
2. **LUT 沒有內建清單，只能匯入 .cube/.3dl 檔案**：影片素材「調整」面板的 LUT 名稱下拉選單只有「無」一個選項；左側導覽列「調整」大類下的 LUT 分頁也只有「+匯入 CUBE 和 3DL 檔案」，沒有任何可直接選用的內建 LUT 素材庫（跟濾鏡/特效/轉場有完整可拖拉素材庫的行為不同）。**因應**：改用「自動調整」（AI 一鍵校色，同樣有強度滑桿）示範一鍵套色+找自然感的技能。
3. **「遮罩轉場」面板的蒙版形狀圖示（線性/鏡面/圓形/矩形等）完全無回應**：位置在影片素材「調整」面板 → 最後一個子分頁「遮罩轉場」→ 上方「遮罩」勾選框打勾後，下方會出現形狀選單，但點擊/雙擊任一形狀圖示（包含課程要求的「線性」）畫面與預覽都毫無變化，沒有出現角度/羽化滑桿。已排除選錯圖示（用截圖放大確認過座標），判斷是這個版本的真實功能故障或需要特定前置條件才能啟用。**因應**：此步驟直接記錄限制、跳過角度/羽化練習，把重心放在「去背」（Remove Background → 自動移除）上，這個功能正常可用。

**後續 Stage 若又遇到類似限制**（功能灰階/無回應/無內建素材），直接照上面的因應模式處理：記錄限制 → 找功能對等的替代操作 → 繼續往下做，不要卡在同一個功能上反覆排查超過 2-3 次嘗試。

## 給 Claude 的操作要點（桌面版自動化技術細節）

沿用 `~/.claude/instructions/windows-desktop-automation.md` 的 pywin32 + pywinauto 套路，但 CapCut 桌面版是 canvas 渲染（UIAutomation 抓不到細節元件），實際上是用「螢幕座標點擊」而非 accessibility tree，額外要注意：

- **DPI 感知必開**：多螢幕環境下，Python 若沒呼叫 `ctypes.windll.shcore.SetProcessDpiAwareness(2)`，`win32gui.GetWindowRect()` 回傳的座標會跟 `ImageGrab` 實際截到的像素對不上（座標會隨著滑鼠最後停留的螢幕 DPI 而漂移）。**每個腳本開頭都要設**。
- **截圖用 `PIL.ImageGrab.grab(bbox=rect, all_screens=True)`**，不要用 `pyautogui.screenshot()`（後者只截主螢幕，多螢幕環境下 CapCut 視窗如果在副螢幕會整張黑圖）。
- **CapCut 會開很多個同名「CapCut」隱藏視窗**（helper process），篩選時用 `win32gui.IsWindowVisible(hwnd) and rect 面積夠大` 排除雜訊，主編輯器窗通常是最大的那個 visible window。
- **素材庫 Pro 判斷**：縮圖左上角有紫色鑽石標記 = Pro 專屬素材，免費帳號可預覽/拖進時間軸但無法匯出（本 PC 已買 Pro，不用再迴避，但换到未購買 Pro 的帳號上要記得繞開）。
- **匯出前置條件**：即使素材免費，完全沒編輯過也無法匯出（版權保護機制），至少要加一個濾鏡或文字圖層才會被判定「已編輯」。
- **多軌 PIP 技巧**：新素材預設會接在同軌尾端，要疊成子母畫面必須拖到「時間上與既有素材重疊 + 垂直方向的空白軌道區」，系統才會自動建新軌。
- **CJK 文字輸入**：`pyautogui.typewrite()` 打繁體中文字會變亂碼（掃描碼機制，跟 `windows-desktop-automation.md` 記錄的 Telegram 案例同一個成因）。如果要打乾淨的中文字，改用剪貼簿貼上法（`Set-Clipboard` + `Ctrl+V`），不要用模擬鍵盤逐字打。
- **素材庫「先選再加」兩段式互動**：音樂/特效/濾鏡/貼圖/文字這些素材庫項目，第一次點擊只會選取+預覽（右側面板切成專案總覽），要再點一次同一個縮圖才會冒出「+」加入按鈕，點「+」才真的加進時間軸。單純雙擊不一定等同兩次單擊，遇到「選了但沒加入時間軸」先試單擊兩次。
- **拖曳素材到時間軸空白處＝強制建新軌**：直接點「+」或雙擊縮圖，素材可能被插入目前選取中的既有軌道（把原本素材往後推），不是疊加。要疊加成新的獨立軌道（如疊人像、疊貼圖），改用滑鼠從素材庫縮圖「拖曳」到時間軸最上方的空白區域。
- **工具列圖示 tooltip 常抓不到**：`SetCursorPos` 純位移不一定觸發原生 hover 事件，tooltip 有時完全不跳出來。與其花時間湊 tooltip，不如直接點下去看跳出什麼面板/對話框更快。
- **LUT 只能匯入，沒有內建清單**；**「遮罩轉場」面板的蒙版形狀圖示會完全無回應**——這兩個功能遇到直接照上方踩坑總表寫的方式跳過/替代，不用重複排查。
- **關鍵幀操作三步驟**（Stage 5 新學到，很重要）：
  1. 選取素材 → 找到要做動畫的屬性（縮放/位置/旋轉/不透明度），這些屬性平常收在對應面板（影片素材在「基礎→轉換」、文字素材在「基礎→轉換」+「不透明度」）
  2. **滑鼠移到該屬性那一列上 hover**，數值框右側才會浮現「‹ ◇ ›」關鍵幀控制列（不 hover 完全看不到，容易誤以為沒有這個功能）
  3. 把播放頭移到要打關鍵幀的時間點 → 精準點擊中間的 **◇ 鑽石本體**（不是滑桿、不是數值框——點太靠左會誤觸滑桿把數值拖走，要點鑽石圖示的正中心）→ 鑽石會變成填滿的**青色實心菱形**確認新增成功；之後只要移動播放頭到別的時間點、直接改數值，就會自動在新位置新增下一個關鍵幀（不用每次都點一次鑽石）
  4. 時間軸上該素材的頂端會出現一整排小白點/鑽石標記，對應每個關鍵幀的位置，可以用來視覺化確認打了幾個
- **Telegram 桌面版通知可能突然搶走視窗焦點、整個蓋住 CapCut**（本次 session 實測踩到）：跳出通知時前景視窗會變成 Telegram，`ImageGrab.grab(bbox=capcut_rect)` 這時候截到的是 Telegram 的畫面內容，不是 CapCut。**處理方式**：
  1. 絕對不要對著看起來像 CapCut 位置的畫面盲點——先截圖確認目前抓到的到底是誰的視窗
  2. 用 `win32gui.EnumWindows` 重新枚舉，確認 CapCut 的 hwnd 是否還存在（通常還在，只是被蓋住，沒有真的關閉）
  3. 用 `win32gui.ShowWindow(telegram_hwnd, win32con.SW_MINIMIZE)` 把 Telegram 縮到最小（用 API 縮小，不要點擊 Telegram 內容本身，避免誤觸私人/公司對話裡的按鈕）
  4. 再用 `AttachThreadInput` + `SetForegroundWindow` 把 CapCut 拉回前景（單純 `SetForegroundWindow` 常因 Windows 焦點鎖定機制失敗，要搭配 `AttachThreadInput`，寫法見 `windows-desktop-automation.md`）
  5. 這類通知彈出是不可預期的，之後每次連續截圖操作前，養成習慣先看一眼截圖內容是否真的是 CapCut 介面，不要照座標無腦連續點擊
